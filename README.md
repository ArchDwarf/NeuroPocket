# NeuroPocket — нейросети прямо на Android

Приложение скачивает и запускает нейросети **на самом телефоне**: вся обработка
идёт на процессоре устройства, интернет нужен только чтобы скачать модель.

- **Чат** с языковыми моделями (llama.cpp).
- **Фото и видео в чате** — модели со зрением (Qwen2.5-VL, Gemma 3/4, SmolVLM2, InternVL…)
  описывают снимки, читают текст на фото, отвечают на вопросы по видео.
- **Картинки** — генерация по описанию, перерисовка фото, перерисовка выделенной
  пальцем области (маска) и редактирование по инструкции (stable-diffusion.cpp).

Движок — [llama.cpp](https://github.com/ggml-org/llama.cpp), поэтому поддерживается
практически любая модель в формате **GGUF**: Llama, Qwen, Gemma, Mistral, Phi, DeepSeek,
SmolLM, Granite и сотни других.

## Возможности

- **Каталог Hugging Face внутри приложения** — поиск по всем GGUF-моделям, выбор
  варианта квантования, фоновая загрузка с прогрессом (продолжается после обрыва сети).
  Можно ввести адрес репозитория напрямую, например `bartowski/Qwen2.5-1.5B-Instruct-GGUF`.
- **Импорт своего .gguf-файла** из памяти телефона (кнопка «Из файла»).
- Модели, разбитые на части (`-00001-of-00003.gguf`), скачиваются и загружаются целиком.
- **Чат** с потоковым выводом, кнопкой «Стоп», перегенерацией ответа и сворачиванием
  «размышлений» (`<think>`) у моделей вроде Qwen 3 / DeepSeek R1.
- Шаблон чата берётся из самой модели; KV-кэш переиспользуется, поэтому
  длинная переписка не пересчитывается заново на каждое сообщение.
- Если переписка не влезает в контекст, старые сообщения автоматически забываются.
- **Настройки**: системный промпт, температура, top-p, top-k, штраф за повторы,
  длина ответа, размер контекста, число потоков, токен Hugging Face для закрытых моделей.
- Под каждый процессор автоматически выбирается самый быстрый вариант кода
  (ARMv8.0 / dotprod / i8mm / SVE).

## Фото и видео

Модели со зрением состоят из двух файлов: сама модель и модуль зрения `mmproj`.
При скачивании из каталога модуль зрения загружается автоматически (модели с ним помечены 👁).
Для своего файла: меню модели → «Подключить зрение (mmproj)».

Видео модель «смотрит» как серию кадров (по умолчанию 6, примерно раз в секунду) —
число кадров и размер фото настраиваются. Каждый кадр обрабатывается как отдельное фото,
поэтому на телефоне видео анализируется от десятков секунд до нескольких минут.

## Картинки

Поддерживаются однофайловые модели Stable Diffusion (`.safetensors`, `.ckpt`, `.gguf`):
SD 1.x / 2.x, SD-Turbo, SDXS, SDXL, inpaint-модели и Instruct-Pix2Pix.

| Режим          | Что делает                                                         |
|----------------|--------------------------------------------------------------------|
| По тексту      | новая картинка по описанию                                          |
| Перерисовать   | фото перерисовывается по описанию; с маской — только закрашенная часть |
| Инструкция     | «make it winter», «add sunglasses» — для edit-моделей (Instruct-Pix2Pix) |

Описания нужно писать **на английском** — так устроены модели Stable Diffusion.
Результат можно сохранить в галерею или продолжить редактировать.
Из видео можно взять любой кадр и отредактировать его.

**Ограничения.** Изменить видео целиком нейросетью на телефоне сейчас невозможно — такие
модели требуют десятков гигабайт видеопамяти. Большие современные модели (FLUX, Qwen-Image,
SD3) состоят из нескольких файлов и требуют 16+ ГБ памяти, поэтому в интерфейсе не поддерживаются.

Скорость на флагманском телефоне: SDXS — секунды, SD-Turbo (4 шага) — ~10–30 с,
SD 1.5 (20 шагов, 512×512) — 1–3 минуты.

## Сборка

Нужно: **Android Studio** (Narwhal или новее) с установленными
*Android SDK 36*, *NDK* и *CMake 3.22.1* (Settings → Languages & Frameworks → Android SDK → SDK Tools).

Проще всего — GitHub Actions: каждый push в `main` собирает APK (вкладка **Actions** → **Artifacts**).

1. Откройте папку `NeuroPocket` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle. При первой сборке CMake сам скачает исходники
   llama.cpp и stable-diffusion.cpp (зафиксированные версии). Первая сборка долгая (20–40 минут).
3. Подключите телефон с включённой отладкой по USB и нажмите **Run ▶**.

Готовый APK из командной строки:

```bash
./gradlew assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

Release-сборка подписана отладочным ключом, чтобы её можно было сразу установить.
Для публикации в магазине настройте собственную подпись в `app/build.gradle.kts`.

## Сборка без интернета / своя версия llama.cpp

Положите исходники в `third_party/`: `llama.cpp`, `stable-diffusion.cpp` и его копию ggml
в `sd-ggml` — CMake возьмёт их вместо загрузки.

## Какую модель выбрать

| ОЗУ телефона | Что подойдёт                                    |
|--------------|-------------------------------------------------|
| 3–4 ГБ       | Qwen 2.5 0.5B, Llama 3.2 1B, Gemma 3 1B (Q4_K_M) |
| 6 ГБ         | Qwen 3 1.7B, Gemma 2 2B, Llama 3.2 3B            |
| 8 ГБ и больше| Qwen 3 4B, Phi-3.5 mini, модели 7–8B в Q4         |

Квантование **Q4_K_M** — лучший баланс качества и скорости. Файл модели должен занимать
заметно меньше оперативной памяти телефона, иначе система может закрыть приложение.

## Устройство проекта

```
app/src/main/
├── cpp/
│   ├── CMakeLists.txt        сборка llama.cpp (+ libmtmd для зрения) и JNI-библиотеки
│   └── llm_jni.cpp           мост Kotlin ⇄ llama.cpp: шаблон чата, картинки, KV-кэш, генерация
└── java/com/neuropocket/app/
    ├── MainActivity.kt       навигация: Чат / Картинки / Модели / Настройки
    ├── engine/               LlamaNative (JNI) и LlamaEngine (корутины, отдельный поток)
    ├── data/                 HuggingFace API, ModelRepository, Media (фото, кадры видео, галерея)
    └── ui/                   экраны Compose, MainViewModel, ImageStudio
sdengine/                     отдельный модуль: stable-diffusion.cpp со своей копией ggml
└── src/main/cpp/sd_jni.cpp   мост Kotlin ⇄ stable-diffusion.cpp
```

## Ограничения

- Вычисления идут на CPU. Ускорение на GPU (Vulkan/OpenCL) можно включить в
  `CMakeLists.txt`, но на многих телефонах оно работает нестабильно.
- Сборка только для arm64-v8a (все современные телефоны), Android 9+.
- Модель картинок собрана под ARMv8.2 (процессоры примерно с 2018 года).
- На телефонах с памятью меньше 11 ГБ чат-модель и модель картинок не держатся в памяти
  одновременно: при переключении одна выгружается автоматически.
