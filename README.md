# NeuroPocket — нейросети прямо на Android

Приложение скачивает и запускает языковые модели **на самом телефоне**: вся обработка
идёт на процессоре устройства, интернет нужен только чтобы скачать модель.

Движок — [llama.cpp](https://github.com/ggml-org/llama.cpp), поэтому поддерживается
практически любая модель в формате **GGUF**: Llama, Qwen, Gemma, Mistral, Phi, DeepSeek,
SmolLM, Granite и сотни других.

## Возможности

- **Каталог Hugging Face внутри приложения** — поиск по всем GGUF-моделям, выбор
  варианта квантования, фоновая загрузка с прогрессом (продолжается после обрыва сети).
  Можно ввести адрес репозитория напрямую, например `bartowski/Qwen2.5-1.5B-Instruct-GGUF`.
- **Импорт своего .gguf-файла** из памяти телефона (кнопка «Из файла»).
- Модели, разбитые на части (`-00001-of-00003.gguf`), скачиваются и загружаются целиком.
- **Чат** с потоковым выводом, кнопкой «Стоп», перегенерацией ответа и сворачиванием
  «размышлений» (`<think>`) у моделей вроде Qwen 3 / DeepSeek R1.
- Шаблон чата берётся из самой модели; KV-кэш переиспользуется, поэтому
  длинная переписка не пересчитывается заново на каждое сообщение.
- Если переписка не влезает в контекст, старые сообщения автоматически забываются.
- **Настройки**: системный промпт, температура, top-p, top-k, штраф за повторы,
  длина ответа, размер контекста, число потоков, токен Hugging Face для закрытых моделей.
- Под каждый процессор автоматически выбирается самый быстрый вариант кода
  (ARMv8.0 / dotprod / i8mm / SVE).

## Сборка

Нужно: **Android Studio** (Narwhal или новее) с установленными
*Android SDK 36*, *NDK* и *CMake 3.22.1* (Settings → Languages & Frameworks → Android SDK → SDK Tools).

1. Откройте папку `NeuroPocket` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle. При первой сборке CMake сам скачает исходники
   llama.cpp (зафиксированная версия) — это займёт пару минут.
3. Подключите телефон с включённой отладкой по USB и нажмите **Run ▶**.

Готовый APK из командной строки:

```bash
./gradlew assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

Release-сборка подписана отладочным ключом, чтобы её можно было сразу установить.
Для публикации в магазине настройте собственную подпись в `app/build.gradle.kts`.

### Сборка без интернета / своя версия llama.cpp

Положите исходники llama.cpp в `third_party/llama.cpp` (например,
`git submodule add https://github.com/ggml-org/llama.cpp third_party/llama.cpp`) —
CMake возьмёт их вместо загрузки.

## Какую модель выбрать

| ОЗУ телефона | Что подойдёт                                    |
|--------------|-------------------------------------------------|
| 3–4 ГБ       | Qwen 2.5 0.5B, Llama 3.2 1B, Gemma 3 1B (Q4_K_M) |
| 6 ГБ         | Qwen 3 1.7B, Gemma 2 2B, Llama 3.2 3B            |
| 8 ГБ и больше| Qwen 3 4B, Phi-3.5 mini, модели 7–8B в Q4         |

Квантование **Q4_K_M** — лучший баланс качества и скорости. Файл модели должен занимать
заметно меньше оперативной памяти телефона, иначе система может закрыть приложение.

## Устройство проекта

```
app/src/main/
├── cpp/
│   ├── CMakeLists.txt        сборка llama.cpp и JNI-библиотеки
│   └── llm_jni.cpp           мост Kotlin ⇄ llama.cpp: загрузка, шаблон чата, KV-кэш, генерация
└── java/com/neuropocket/app/
    ├── MainActivity.kt       навигация: Чат / Модели / Настройки
    ├── engine/               LlamaNative (JNI) и LlamaEngine (корутины, отдельный поток)
    ├── data/                 HuggingFace API, ModelRepository (загрузки, импорт), настройки
    └── ui/                   экраны на Jetpack Compose и MainViewModel
```

## Ограничения

- Вычисления идут на CPU. Ускорение на GPU (Vulkan/OpenCL) можно включить в
  `CMakeLists.txt`, но на многих телефонах оно работает нестабильно.
- Поддерживаются текстовые модели. Мультимодальные (картинки, звук) и модели других
  форматов (ONNX, TFLite, safetensors) потребуют конвертации в GGUF или другого движка.
